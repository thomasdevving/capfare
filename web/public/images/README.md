# Landing hero photograph

`hero-flight.webp`: photograph by Johan Van Wambeke, downloaded from Unsplash
and encoded as a 2400 × 1400 WebP for local hosting (no third-party image request).

Source: https://unsplash.com/photos/_2VioFUgQVg
Image: https://images.unsplash.com/photo-1551748629-08d916ed6682
License: https://unsplash.com/license

`hero-flight-capfare.webp` is an AI-assisted edit of the source photograph, made
with the built-in image generation tool. The scene is mirrored to place the sun
and wingtip on the right; red livery accents are changed to CapFare yellow and
the supplied CapFare logo is painted on the wing in perspective. The generated
asset is already oriented for the hero and must not be mirrored with CSS.
