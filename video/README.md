# CapFare demo film

A demo and explainer film for the NEAR Hackathon, made from real recordings of the CapFare app
on NEAR testnet, with motion graphics, burned-in captions and placeholders for a webcam and a
voice-over. Two cuts:

* **Full version** (3:45.5): every feature and scenario, and a chapter on how CapFare uses NEAR.
* **X cut** (2:16.5): the same story, shorter scenes, a few scenes left out.

Paperwork, generated from the same timeline:

* [`SCRIPT.md`](SCRIPT.md): every scene with timecodes, on camera or voice-over, and the caption lines.
* [`CHECKLIST.md`](CHECKLIST.md): each feature and scenario with its timecodes in both cuts.
* [`WEBCAM.md`](WEBCAM.md): where and when the webcam placeholder is, in pixels and seconds.
* [`X-POST.md`](X-POST.md): text for the post on X.
* `captions-<cut>.srt`, `webcam-<cut>.json`, `cues-<cut>.json`: captions, webcam rects, sound cues.

## How it is made

```
record/   takes.cjs       records the app with the Chrome DevTools screencast (not a screen recorder)
          lib.cjs         recorder: visible cursor, eased mouse and scrolling, click and wait marks
          evidence.cjs    reads a real meta-transaction, its receipts, accounts and keys from testnet
film/     timeline.js     the single source of truth: scenes, lengths, lines, X cut, webcam spots
          film.html/.js   the film as a web page: renderFrame(t) draws any moment, nothing animates by itself
          shots.js        which part of which recording plays in each scene, and how the camera moves
          evidence.js     generated by evidence.cjs
render/   render.cjs      renders frames with Playwright (60 fps, 3 workers, resumable)
          export.cjs      writes SCRIPT.md, CHECKLIST.md, WEBCAM.md, captions and webcam json
          encode.sh       frames + audio -> MP4
          composite.py    puts your webcam and voice into a rendered cut
          inspect.py      a recording's timeline and contact sheet, to plan shots
          clean_footage.py, sheet.py, frames.py   small helpers
audio/    music.py        music, sound effects and mix, synthesised with numpy and scipy
```

Recordings are real: the web app, the Chrome extension and the Skyline Travel demo booking site,
running against the CapFare contracts on NEAR testnet (`*.v2.capfare.testnet`), with the demo
price source. Waits for the chain are cut out of the footage with a short dissolve, and marked
as such in the recording (`label:begin` / `label:end` in each take's `events.json`).

## Re-render

Requirements: Node 20+, Playwright's Chromium, Python 3 with numpy, scipy and Pillow, ffmpeg.
Footage, frames and audio are not in git (`video/footage`, `video/frames`, `video/out`,
`video/audio/*/`); the steps below recreate them.

1. Run the stack against testnet with the web app on port 3000 (see `docs/TESTNET.md`), then record:

   ```bash
   node video/record/takes.cjs
   ```

   Takes already done are skipped; name takes to redo them (`node video/record/takes.cjs claim lp`).
   Shared state (account, policy ids, booking emails) is kept in `video/footage/state.json`. The
   contract allows a few policies per user per flight, so a long session may need a second account:
   `REC_PROFILE=.profile-main2` with a new `mainName` in `state.json`, then name the takes to record.

2. Clean the footage and collect the chain evidence:

   ```bash
   python3 video/render/clean_footage.py
   ```

   ```bash
   node video/record/evidence.cjs
   ```

3. Check the plan: `python3 video/render/inspect.py <take>` prints a take's clicks on the
   compressed timeline; edit `film/shots.js`. To look at moments of the film:

   ```bash
   node video/render/render.cjs --times 20,45.5,130
   ```

   or `--sample 20` for 20 evenly spaced stills (in `video/out/<cut>/stills`), then
   `python3 video/render/sheet.py video/out/full/stills sheet.jpg` for a contact sheet.
   Opening `film/film.html?t=45.5` through any static server shows one frame too.

4. Render all frames (resumable: run again after an interruption, finished frames are kept):

   ```bash
   node video/render/render.cjs --cut full
   ```

   ```bash
   node video/render/render.cjs --cut x
   ```

5. Music and effects (reads the cues written in step 4), paperwork, and the MP4s:

   ```bash
   python3 video/audio/music.py full && python3 video/audio/music.py x
   ```

   ```bash
   node video/render/export.cjs
   ```

   ```bash
   video/render/encode.sh full && video/render/encode.sh x
   ```

Audio stems in `video/audio/<cut>/`: `music.wav` (not ducked), `sfx.wav`, `vo-timing.wav` (a soft
guide tone while each caption is on screen, for timing a real voice-over; not in the mix) and
`mix.wav` (music ducked about 9 dB under the voice-over spans, plus effects).

## Compositing the webcam and voice-over

The film has placeholders, not a presenter or a synthetic voice. To add yours:

1. Read the lines from `SCRIPT.md` while the film plays, recording your webcam and microphone from
   the moment the film starts (or note the offset). `vo-timing.wav` and the captions show when
   each line starts.
2. Composite:

   ```bash
   python3 video/render/composite.py --cut full --camera cam.mp4 --voice voice.wav
   ```

   Each placeholder in `webcam-<cut>.json` is replaced by your camera at that time, scaled to fill
   the rect, masked to its circle or rounded rectangle, with the same fades; the voice is mixed
   over music (side-chain ducked) and effects. Use `--offset 1.5` if the camera started 1.5 s late.

In an editor instead: put `out/<cut>/<cut>.mp4` on the bottom track and your camera above it,
scaled and masked to the rects in `WEBCAM.md`; mute the film's audio and use `audio/<cut>/music.wav`
and `sfx.wav` with your voice.

## Look and sound

Palette from the app (navy `#0b2447`, ink `#0b1024`, yellow `#FFD100`, blue `#0f5fc2`, light
`#f2f6fb`), Outfit for headings, Atkinson Hyperlegible Next for text. Calm eased motion at 60 fps,
transitions are a two-band diagonal wipe or a circle iris, confirmations are a round check badge
with text. Music: 112 bpm, D major, I-V-vi-IV, soft kick, clap on 2 and 4, shaker, bass,
Karplus-Strong plucks and a bell hook; soft effects on wipes, clicks, check badges and cards.
